# Контракты

Здесь лежат контракты между частями системы, и ссылки на исполняемые Pydantic-модели. Что такое контракт и кто за какой отвечает — в [ARCHITECTURE, п. 3](../ARCHITECTURE.md#3-контракты-между-частями).

| Контракт | Файл | Пишет | Ревьюит | Состояние |
| :--- | :--- | :---: | :---: | :--- |
| K3. Вход и выход расчетного ядра | [engine.md](engine.md), `services/engine/contracts.py` | Арина | Александр | Контракт в `develop` |
| K4. REST API | [api.md](api.md), `services/api/schemas.py` (позже — OpenAPI из FastAPI) | Александр | Максим, Григорий | Контракт в `develop`; HTTP-обработчик не реализован |

Схема БД (K2) описана в [data/ERD.md](../data/ERD.md), маппинги внешних источников (K1) — в [data/s2t/](../data/s2t/).

**Что должно быть в контракте:**
* какие данные передаются: поля, типы, единицы измерения, обязательность;
* пример входа и выхода;
* ошибки и как о них сообщается;
* на какие требования и ADR он опирается (для ядра — [ADR-001](../adr/ADR-001-engine-input-data.md)).
