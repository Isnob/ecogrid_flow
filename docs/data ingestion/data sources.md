Технологии: APScheduler / Celery Workers
Ключевые функции: автоматическая загрузка по расписанию, повторные попытки при сетевых ошибках и предварительная проверка качества данных.
Каталог источников данных EcoGrid Flow

[!TIP] Объёмы являются оценкой для MVP и уточняются после выбора энергозон и дата-центров.

Обоснование выбора исторических источников
Для исторических цен и структуры генерации выбран ENTSO-E Transparency Platform, потому что он публикует временные ряды по энергозонам и отдельные данные по Day-Ahead ценам и типам генерации в машиночитаемом формате. Источник подходит для EDA и дальнейшей подготовки признаков ML-модели.
Для исторической погоды выбран Open-Meteo Historical Weather API: он принимает координаты, даты и список погодных переменных, а архивные данные доступны за длительный период. Это позволяет связать погоду с конкретным ЦОД через координаты.
Исторические ряды необходимо импортировать в таблицы entsoe_day_ahead_prices, entsoe_day_ahead_generation и open_meteo_historical_weather. Перед ETL нужно проверить через выданный токен ENTSO-E доступность нужного периода и выбранных энергозон.
[!WARNING] Доступ к источникам различается. Для ENTSO-E нужны регистрация, роль Web API Consumer и Security Token. Для Open-Meteo некоммерческого использования ключ обычно не требуется. Таблицы datacenters, jobs и recommendations зависят от доступа к внутренней инфраструктуре клиента.

2.2. Storage Layer (Хранилище данных)
Технологии: PostgreSQL 16 с партиционированием временных рядов.
Схема хранения согласована со спецификацией PreColumns.md:
entsoe_day_ahead_prices — цена по энергозоне и временному интервалу: bidding_zone, period_start, period_end, price, currency, price_unit, resolution.
entsoe_day_ahead_generation — генерация по типам источников: bidding_zone, period_start, period_end, production_type, generation_mw, resolution.
open_meteo_forecast — прогноз около ЦОД: координаты, время прогноза, температура, влажность, ветер и радиация.
open_meteo_historical_weather — исторические метеоданные: координаты, observed_at, температура, влажность, облачность, ветер и радиация.
datacenters — справочник инфраструктуры и связь ЦОД с энергозоной.
jobs — параметры вычислительных задач.
recommendations — результаты расчётов и история рекомендаций.
Так источники из каталога однозначно сопоставлены с предполагаемыми таблицами БД из PreColumns.md.
